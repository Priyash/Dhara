# Dhara — Frontend

React 18 + Vite + CSS Modules frontend for the Dhara Bengali OTT platform.

See the [root README](../README.md) for full setup instructions, environment variables, and feature overview.

## Dev

```bash
# From the repo root
npm run dev

# Or from this directory
npm install
npm run dev
```

Runs on `http://localhost:5173` and proxies API calls to `http://localhost:4000`.
